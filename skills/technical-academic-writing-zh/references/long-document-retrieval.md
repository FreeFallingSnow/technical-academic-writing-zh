# 长文问题句检索

处理大段文字、多章节文稿或全文审校时，先做轻量全局筛选，再对候选句及其上下文执行深度判断。不得对所有句子进行同等强度的改写，也不得只凭关键词删除内容。

## 1. 建立候选句集合

按章节、段落和句子保留位置编号。依次加入三类候选：

1. 命中可疑词组合的句子；
2. 命中可疑结构的句子；
3. 每个段落的末句。

同一句命中多个条件时提高检查优先级。候选集合只用于定位，不直接决定修改。

## 2. 可疑词组合

### 证据强度叠加

重点检索同一句或相邻两句中共同出现的词组：

- `可能`、`或许`、`提示`、`支持`、`表明`；
- `仅`、`只支持`、`受……限制`、`尚不能`、`不能单独`、`仍需`、`有待`；
- `不能确定`、`无法证明`、`不排除……可能`。

前一句已经使用“可能、提示”等词，后一句又出现第二组或第三组表达时，必须检查是否重复限定。

### 修改过程痕迹

检索：

- `根据意见`、`根据审阅意见`；
- `本次修改`、`修改后`、`修订后`；
- `补充说明`、`重新整理`、`保持不变`；
- `修改如下`、`调整如下`。

这些表达出现在技术或学术正文时列为高优先级候选。

### 否定性绕行

检索：

- `并非不能`、`并不是没有`；
- `不再继续`、`未再继续`；
- 连续出现两个以上`不`、`未`、`无`、`不能`或`不得`的句子；
- `不能排除……可能`之后继续解释同一可能性。

安全禁令、阴性结果和排除条件也会命中这些词。命中后必须判断其技术意义，不得直接删除。

排除句出现“未采用”“未使用”“不考虑”或“排除”及其对象时，继续检索该对象及其同义称谓在正文、表格、图注、附录和当前可访问引用材料中的位置。对象在全文材料中没有定义、用途或参与路径，且当前方法已经完整陈述时，将该句标为孤立排除项；对象在其他位置承担输入、标定、计算、比较或验证作用时，检查该句是否构成必要的方法边界。

### 元说明与重复总结

检索：

- `为避免误解`、`需要说明`、`需指出`、`本处说明`；
- `综上`、`由此可见`、`因此可知`、`上述结果表明`；
- `总体而言`、`可以看出`、`这说明`。

这些词位于段落末句时提高检查优先级，重点判断该句是否只复述前文。

## 3. 可疑结构

出现以下结构时加入候选集合：

- 一个句子包含两个以上可独立成句的主要判断；
- 条件、原因、结果和评价由多个连接词串联在同一句中；
- 主语在句中改变，但后半句仍使用“其、该情况、这”等指代；
- 同一对象、动作或结论在相邻两句中以近义词重复；
- 同一数值、条件和判断同时出现在正文与摘要、图注或结论中；
- 后一句没有新增对象、数据、条件或逻辑关系，只改换说法；
- 段落首句和末句表达相同判断，末句没有推进论证。

不得使用固定字数作为唯一标准。句长只用于提示，判断依据是信息和逻辑结构。

## 4. 段落末句加权

每个段落的末句必须进入候选集合，包括没有命中关键词的末句。

检查末句时，至少同时读取：

- 当前段落标题；
- 末句之前的两句；
- 下一段首句（若存在）；
- 与该段对应的摘要或结论句（若存在）。

末句满足以下任一条件时列为高优先级：

- 含有证据强度词和限制词；
- 以“综上、因此、这表明、需要说明”等词起句；
- 与前两句共享主要对象和判断，却没有新增信息；
- 再次解释本段已经表达的范围或不确定性；
- 用总结句重复正文数据和推理。

段落末句承担必要结论、转折或衔接时必须保留。段末位置只提高检查优先级，不构成删除理由。

## 5. 检查顺序

按以下顺序处理候选：

1. 同时命中可疑词、可疑结构和段末位置的句子；
2. 命中修改痕迹或证据强度叠加的句子；
3. 与摘要、结论或相邻段落重复的句子；
4. 只命中结构条件的句子；
5. 仅因位于段末而进入集合的句子。

对每个候选句读取规定的上下文，再执行 `SKILL.md` 中的保留测试。涉及排除对象时，还要完成该对象的全文和可访问引用材料检索。没有通过保留测试的句子必须删除；存在独立信息但结构不清的句子必须重组。

## 6. 修改后复检

完成修改后重新检查：

- 所有被修改段落的末句；
- 修改位置前后各一个段落；
- 与修改内容对应的摘要、表格和结论。

没有新增高优先级候选后结束。不得通过多轮同义改写反复处理已经满足规范的句子。
